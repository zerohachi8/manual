Canva MCP に接続できない

Claude Code から Canva ツール（copy-design / export-design 等）が使えないときの復旧手順。

📋 症状→対処 早見表

症状原因対処
セッション中に Canva ツールが急に消えた／使えなくなった セッション中の MCP 切断（ツール一覧は会話開始時に固定） 新しいセッションを開くだけで復活
claude mcp list に canva が無い MCP 未登録 下の STEP A で登録
! Needs authentication と表示 認証未完了 下の STEP B で認証
claude.ai コネクタで「切断する」ボタンが見える 接続済み（正常） 新セッションを開けば使える

STEP ACanva MCP を登録する

ターミナルで以下を実行：

claude mcp add --transport http canva https://mcp.canva.com/mcp

登録確認：

claude mcp list

canva: https://mcp.canva.com/mcp (HTTP) が表示されれば登録OK。

STEP B認証（OAuth）する

  1. ターミナルで claude を起動（インタラクティブモード）
  2. チャット内で /mcp を入力
  3. Canva の認証URLが表示されるのでブラウザで開く
  4. Canva アカウントでログイン →「許可する」

代替：claude mcp auth canva（バージョンにより）

STEP Cclaude.ai コネクタ側の確認

  • デスクトップアプリまたは claude.ai → 左メニュー 設定 → コネクタ
  • Canva を探す
    • 「接続する」ボタン → 未接続。押して OAuth 完了させる
    • 「切断する」ボタン → 接続済み（正常）
⚠️ 重要な仕様
・ツール一覧は会話開始時に固定される。会話の途中で MCP を追加・再認証しても、その会話には反映されない → 必ず新しいセッションを開く
・非対話（headless／バックグラウンド）セッションでは OAuth フローを実行できない → 必ずインタラクティブな claude ターミナルで認証
・認証は一度完了すれば、以後の新セッションで自動的に使える

🔍 検証ずみ復旧例（2026-07-03）

  • 症状：mcp__plugin_small-business_canva__* が Tool Search でヒットしない
  • 実際の状態：claude mcp list に canva が未登録
  • 対処：STEP A で登録 → Needs authentication → 別ターミナルで STEP B → 新セッションで復活

Google Workspace MCP：OAuth クライアントを「AIエージェント」にする（期限 2026-11-11）

Google から「【対応必須】2026年11月11日までに Google Workspace MCP の AI エージェント OAuth クライアントをエージェントとしてマークしてください」というメールが届いたときの対応手順。

📅 スケジュール

日付内容
2026-10-12Google Cloud コンソールでクライアントを「エージェント」にできるようになる
2026-11-11エージェント指定のないクライアントからの Workspace MCP 呼び出しを拒否（エラー：クライアントが AI エージェントとしてマークされていません）
2026-11-12設定が固定。以後の変更は新しい OAuth クライアント ID の作成が必要

🔎 対応が必要かの判断

  • Claude などの AI から Workspace MCP（Gmail／Drive／Calendar）に接続する OAuth クライアントがある → 対応必要
  • Gmail API／Drive API などの REST API のみ使っている → 対応不要
  • 人間用アプリと AI 用を同じクライアントで共用している → エージェント用に別クライアントを新規作成（公式推奨）

手順チェックを入れる

  1. Google Cloud コンソールを開き、対象プロジェクトを選択
  2. Google Auth Platform → クライアント で対象の OAuth クライアントを開く
  3. Use this client for an AI-powered agent にチェック
  4. 「保存」→ 確認ダイアログ Change AI agent classification? で「保存」
  5. トースト「OAuth クライアントを保存しました」を確認 → ページを再読み込みしてチェックが残っていることを確認
⚠️ 注意
・保存はダイアログの「保存」まで押して初めて確定。画面が ON でも、ダイアログ未確定だと再読み込みで OFF に戻る
・MCP 側で有効になるまで 5 分〜数時間かかる場合あり
・チェックを入れても、スコープや権限は増えない（自己申告の分類のみ）
・2026-11-12 以降は変更不可。変える場合は新しいクライアント ID を作成

🔍 実施記録（2026-10-14）

  • プロジェクト：itoai1（メールでは「itoi1」表記）／クライアント：itoai1（デスクトップ型・1件のみ）
  • チェックを入れて保存し、再読み込みで ON を確認
  • 参考：OAuth クライアントの管理（Google）／Workspace MCP サーバーの設定（Google）

セッションタイトルの自動設定

「新規作成」を押して最初の依頼を送ると、Claude が 【区分】説明_MMDD と参照先を付ける。区分は【FJ】【仕事】【管理】の3つ。それ以外の依頼では付けない。再開したセッションでは変更しない。

⚠️ 付かない時
~/.claude/hooks/require-spec-confirmation.sh と ~/.claude/CLAUDE.md「セッションタイトル自動設定」を確認する
