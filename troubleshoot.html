Canva MCP に接続できない

Claude Code から Canva ツール（copy-design / export-design 等）が使えないときの復旧手順。

📋 症状→対処 早見表

症状原因対処
セッション中に Canva ツールが急に消えた／使えなくなった セッション中の MCP 切断（ツール一覧は会話開始時に固定） 新しいセッションを開くだけで復活
claude mcp list に canva が無い MCP 未登録 下の STEP A で登録
! Needs authentication と表示 認証未完了 下の STEP B で認証
claude.ai コネクタで「切断する」ボタンが見える 接続済み（正常） 新セッションを開けば使える

STEP ACanva MCP を登録する

ターミナルで以下を実行：

claude mcp add --transport http canva https://mcp.canva.com/mcp

登録確認：

claude mcp list

canva: https://mcp.canva.com/mcp (HTTP) が表示されれば登録OK。

STEP B認証（OAuth）する

  1. ターミナルで claude を起動（インタラクティブモード）
  2. チャット内で /mcp を入力
  3. Canva の認証URLが表示されるのでブラウザで開く
  4. Canva アカウントでログイン →「許可する」

代替：claude mcp auth canva（バージョンにより）

STEP Cclaude.ai コネクタ側の確認

  • デスクトップアプリまたは claude.ai → 左メニュー 設定 → コネクタ
  • Canva を探す
    • 「接続する」ボタン → 未接続。押して OAuth 完了させる
    • 「切断する」ボタン → 接続済み（正常）
⚠️ 重要な仕様
・ツール一覧は会話開始時に固定される。会話の途中で MCP を追加・再認証しても、その会話には反映されない → 必ず新しいセッションを開く
・非対話（headless／バックグラウンド）セッションでは OAuth フローを実行できない → 必ずインタラクティブな claude ターミナルで認証
・認証は一度完了すれば、以後の新セッションで自動的に使える

🔍 検証ずみ復旧例（2026-07-03）

  • 症状：mcp__plugin_small-business_canva__* が Tool Search でヒットしない
  • 実際の状態：claude mcp list に canva が未登録
  • 対処：STEP A で登録 → Needs authentication → 別ターミナルで STEP B → 新セッションで復活
